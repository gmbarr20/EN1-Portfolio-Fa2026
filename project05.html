Project 5: Spirograph

Question

For this project, the challenge was use the parts included in the LEGO Spike Prime set to create a spirograph drawing robot. Students also had access to the codespace for the Spike Prime hub block if that was part of their solution

Process

We began by building the spinning base with a motor and some rubber bands for grip. We added the floating platform next to house the second motor and the drawing arm. We then added the stabilization arm and tinkered with the exact placement of the pegs to get a good spirograph drawing. We then used generative AI to make code for the Spike Prime hub block, causing the drawing platform motor to spin slower than the drawing arm motor, which gave us our final spirograph drawing. The spirograph drawing can be changed by modifying the placement of the pins on the drawing and stabilizing arms.

Result

The result of our process is the spirograph drawing robot seen in the images above. With multiple possible adjustments and variable speed through the code software, many different spirographs can be made. There is also a video if you wish to see our robot in action.
